# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

交班台：校准员点「交班」把当时全部排队中（pending）与领取中（claimed）任务的编号、灯种、标称冻结成只读副本；历史副本与副本明细在「交班台」页翻阅，任务随后结案不影响副本内容。巡检员可翻阅副本，不可交班。

## 启动

```bash
cd projects/16-spectrum-wavelength-desk
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理（排队中/领取中）再出超差。
3. inspector 不能提交。
4. 队列留两笔未结时到校准员「交班台」点交班，副本写出这两笔；随后其中一笔结案，再打开该副本仍是交班那一版两笔。
5. inspector 可进交班台翻阅历史副本与明细，交班按钮不可点（接口同样 403）。
